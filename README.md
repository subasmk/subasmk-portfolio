## 📌 About the Project

This is my personal developer portfolio — a **NeoBrutalist** showcase of my skills, coding stats, and personality.  
Built with pure HTML, Tailwind CSS, and vanilla JavaScript. No frameworks, no bloat. Just raw code with attitude.

The design breaks conventional aesthetics with hard shadows, bold colors, glitch effects, and a custom cursor.  
It also integrates live GitHub & LeetCode stats using their public APIs.

---

## ✨ Features

- 🖱️ **Custom cursor** with interactive hover effects
- 📊 **Live GitHub stats** (repos, followers, contributions)
- 🏅 **LeetCode badges** & activity heatmap
- 📜 **Animated marquee** ticker
- 🎨 **NeoBrutalist design** – hard shadows, bold typography, raw layout
- 📱 Fully responsive (mobile friendly)
- 🔍 SEO optimized + JSON-LD structured data
- 🖼️ Ready for future project & experience updates
