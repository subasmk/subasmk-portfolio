## What's inside

- **Animated hero** - particle network canvas, typing role ticker, live GitHub stats pulled from the API
- **Projects** - TrackMe (open-source Android habit tracker, v3.0) and MockMentor (AI mock-interview platform, hackathon build) with real screenshots and live links
- **Skills arsenal** - GenAI/LLMs, full stack, app dev, cybersecurity, tools
- **2026 quest log** - hackathons, SIH, releases, building in public
- **Contact** - mailto-based form (no backend, nothing stored)
- Custom cursor, scroll progress, reveal-on-scroll, card tilt, mobile menu - all vanilla JS, no libraries
